# SZU-Campus-AutoLogin | 深圳大学校园网开机自动认证工具

一个轻量、零延迟、开机即用的深圳大学宿舍区校园网（Dr.COM / ePortal `172.30.255.42`）Windows 自动认证脚本，支持智能网络识别（插网线自动登录、在家连 Wi-Fi 自动退出）。

## ✨ 功能特性

* **开机零延迟自启**：通过 Windows 任务计划程序（`Task Scheduler`）在用户登录瞬间秒级触发，彻底关闭 Windows 11 默认的 15~30 秒启动应用延迟。
* **智能网络环境识别**：
  * **在宿舍插网线**：自动检测深大网关 `172.30.255.42` 并发送认证请求。
  * **在家里/校外连 Wi-Fi**：自动识别并于 2~4 秒内静默退出，不乱发登录请求，不影响正常连接家庭 Wi-Fi。
  * **未插网线**：检测到物理有线网卡未连接时自动退出。
* **双重接口认证保障**：优先使用深大宿舍区 Web ePortal GET 接口，连通性异常时自动启用 Dr.COM 客户端 POST 接口兜底。
* **无黑框防重复守护**：采用 VBScript (`wscript.exe`) 静默时间戳守护锁，彻底解决 Windows 开机重复弹窗、二次弹出的问题。

## 🚀 快速上手

### 1. 修改账号密码

1. 下载 `szu_campus_autologin_universal.bat`。
2. 右键该文件 -> 选择 **“在记事本中编辑”**（或用任意文本编辑器打开）。
3. 找到最顶部的两行，将账号和密码修改为你自己的深大校园网账号密码：
   ```bat
   set "SZU_ACCOUNT=你的校园卡号"
   set "SZU_PASSWORD=你的上网密码"
   ```
4. 按 `Ctrl + S` 保存并关闭记事本。

> 💡 **小贴士**：如果你忘记在记事本中修改，直接双击运行脚本也会在黑色窗口中友善提示你现场输入账号和密码，输入后同样会自动保存。

### 2. 双击运行安装

1. 双击运行修改好的 `.bat` 文件。
2. 若弹出 Windows“打开文件 - 安全警告”，**取消勾选**“打开此文件前总是询问”，然后点击“运行”。
3. 若弹出“用户账户控制 (UAC)”管理员权限提示，点击“是”。
4. 脚本会自动完成自检、注册开机任务并执行一次联网测试。

### 3. 安装完成

看到窗口提示 `[配置完成]` 并在倒数后关闭，即代表配置成功！**桌面上的 `.bat` 安装包可以直接删除**，核心程序已安全备份至系统目录。

以后每次开机插着网线进入桌面，电脑都会在后台自动完成认证！

## 🛠️ 常见问题

&lt;details&gt;
&lt;summary&gt;&lt;b&gt;Q1: 以后修改了校园网密码怎么办？&lt;/b&gt;&lt;/summary&gt;

你可以随时通过以下两种方式之一修改密码：
1. 重新修改下载的 `.bat` 文件顶部密码并运行一次；
2. 或者直接打开 `C:\Users\Public\SZU_AutoLogin_Only\szu_autologin.ps1`（右键记事本编辑），修改里面的密码保存即可。
&lt;/details&gt;

&lt;details&gt;
&lt;summary&gt;&lt;b&gt;Q2: 为什么开机后浏览器还是弹出了校园网登录页？&lt;/b&gt;&lt;/summary&gt;

这是 Windows 系统的 NCSI（网络连接状态探测）机制在刚插网线时触发的。无需担心，脚本通常会在 2~5 秒内自动完成认证，直接关闭该网页即可正常上网。
&lt;/details&gt;

&lt;details&gt;
&lt;summary&gt;&lt;b&gt;Q3: 如何彻底卸载本工具？&lt;/b&gt;&lt;/summary&gt;

若毕业离校不再需要自动登录，按 `Win + R` 输入 `taskschd.msc` 打开“任务计划程序”，找到 `SZU_Campus_AutoLogin_Only` 右键删除，并清空 `shell:startup` 启动目录下的相关文件即可。
&lt;/details&gt;
